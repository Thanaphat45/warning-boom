# เว็บไซต์ตารางหน้าที่พยาบาล

## เป้าหมายและผู้ใช้

เว็บไซต์ภาษาไทยสำหรับพยาบาลคนหนึ่งจดหน้าที่ช่วงกลางวันให้เร็ว ผู้ใช้เห็นงานวันนี้และสัปดาห์นี้ได้ทันที จัดตารางเอง และใช้ร่วมกันกับอีกคนบนตารางเดียวกันได้

## ความสามารถ

- ปฏิทินรายเดือน, หน้าวันนี้, และรายการหน้าที่รายสัปดาห์ที่ปรับตามมือถือ
- เพิ่ม/แก้/ลบหน้าที่ต่อวัน; ตัวอย่างเริ่มต้น: เวรเปิดประตู ห้องยา ห้องแผล เยี่ยมบ้าน และสต็อกเวชภัณฑ์
- สีประจำแต่ละชื่อเวรเหมือนกันในรายการ ปฏิทิน และรายการสัปดาห์
- คัดลอกจากวันก่อนหน้า; แก้ไขและตรวจดูได้ก่อนบันทึก
- ทำเครื่องหมายแต่ละหน้าที่ว่าเสร็จแล้ว
- สรุปจำนวนหน้าที่รายเดือน
- แม่แบบรายสัปดาห์ที่ตั้งชื่อและบันทึกจากสัปดาห์หนึ่ง เพื่อนำไปใช้กับสัปดาห์อื่นได้ การใช้แม่แบบแทนข้อมูลสัปดาห์เป้าหมายหลังผู้ใช้ยืนยัน
- ดาวน์โหลด JSON สำหรับสำรอง/กู้คืน และพิมพ์หรือบันทึกมุมมองตารางปัจจุบันเป็น PDF; PDF ใช้กู้คืนข้อมูลไม่ได้
- ใช้ localStorage ได้โดยไม่ต้องเข้าสู่ระบบ และมีโหมดซิงก์ฐานข้อมูลสำหรับเจ้าของกับผู้ร่วมใช้งานที่ได้รับอนุญาตดู/แก้ตารางเดียวกัน
- แจ้งเตือน Web Push บนโทรศัพท์สำหรับวันที่มีหน้าที่ แม้ปิดเว็บ โดยค่าเริ่มต้นเตือน 20:00 คืนก่อนหน้า; ผู้ใช้เลือกเวลา/วันเตือนได้และเปิด/ปิดเอง

## แนวทางและสมมติฐาน

- คงเว็บสแตติก HTML/CSS/JavaScript ปัจจุบัน ไม่เปลี่ยนเฟรมเวิร์กโดยไม่จำเป็น
- ใช้ Supabase Auth และ Postgres สำหรับบัญชีและข้อมูลแชร์ และ GitHub Pages สำหรับเผยแพร่หน้าเว็บ
- ใช้ Supabase Cron เรียก Edge Function ส่ง Web Push; ใช้ VAPID public key ใน client และเก็บ private key/cron secret ฝั่ง server เท่านั้น
- ผู้ร่วมใช้มีบัญชีแยกกันและแชร์ตารางเดียว; จะไม่แชร์รหัสผ่านบัญชีเดียวกัน
- localStorage ยังคงใช้ได้เมื่อออฟไลน์; ข้อมูลจะไม่ถูกส่งไปคลาวด์จนกว่าผู้ใช้ตั้งค่าบริการและยืนยันการซิงก์
- iPhone/iPad ต้องเพิ่มเว็บลงหน้าจอโฮมเพื่อใช้ Web Push; รองรับตั้งแต่ iOS/iPadOS 16.4
- การย้ายข้อมูลเดิมให้คลาวด์ต้องบอกผู้ใช้และยืนยันก่อน
- หน้าที่หนึ่งรายการต่อวันตามโมเดลในเว็บปัจจุบัน; ไม่ทำ auto-scheduling หรือจัดเวรให้ทั้งทีม

## นอกขอบเขต

- การเชื่อมกับระบบโรงพยาบาล
- นำเข้า PDF เป็นข้อมูลแก้ไขได้
- การตั้งกฎจัดเวรอัตโนมัติ

## รายละเอียดให้ผู้พัฒนาตัดสินใจ

หน้ารายวันและสัปดาห์ต้องทำเครื่องหมายงานเสร็จได้โดยไม่เปิดโมดัล ใช้แม่แบบต้องยืนยันก่อนเขียนทับสัปดาห์ ใช้ฐานข้อมูลบังคับสิทธิ์ระดับแถว และอธิบายขั้นตอนติดตั้งเว็บ/ตั้งค่าการแจ้งเตือนที่เจ้าของบัญชีต้องทำเอง
